What happens when you type docker run node:22-alpine
1
The client sends the command to the daemon.
2
The daemon looks for node:22-alpine in the host's local images.
3
It's not there, so the daemon pulls it from the registry (Docker Hub).
4
The daemon creates a container from the image and starts it.
Run it a second time and step 3 is skipped, because the image is already on the host. To share your own image, docker push sends it the other way.

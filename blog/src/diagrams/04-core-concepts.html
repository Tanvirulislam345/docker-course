The 4 building blocks
Image · Container · Volume · Network
📄

Dockerfile

Text file with build steps

🧾 the recipe
➜docker build
📦

Image

Read-only package: code + runtime + libraries

🍱 a frozen meal / a class
➜docker run
🟢

Container 1

A running copy of the image

🟢

Container 2

Same image, separate & isolated

🟢

Container 3

🍽️ the served dish / an object

💾

Volume

Storage that lives outside the container. Delete the container — your database files are still safe.

🌐

Network

Lets containers talk to each other by name, e.g. the API reaches MongoDB at db:27017.

⚡ Why this order?

Docker reuses every layer until the first one that changed. Dependencies change rarely, so copy package.json and install before copying your code. Editing a component then rebuilds in seconds.

🟢 What docker run does

Stacks a thin writable layer on top of the read-only image, sets the ENV values and runs CMD. Delete the container and only that thin layer is gone — the image stays.

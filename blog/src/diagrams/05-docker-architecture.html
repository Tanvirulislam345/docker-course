How Docker works
Client → Docker Host (Daemon) → Registry

💻 Docker Client

The CLI you type into
$ docker build
$ docker pull
$ docker run
The client only sends requests (REST API). It does no heavy work itself.

🖥️ Docker Host

Your machine / server running Docker
⚙️ Docker Daemon (dockerd)The engine: builds images, starts/stops containers, manages volumes & networks

📦 Images

node:22-alpine
react-docker
mongo:latest

🟢 Containers

react-app

☁️ Registry

Docker Hub, GHCR, AWS ECR…
node
mongo
nginx

Like GitHub, but for images. pull to download, push to share.

Docker Compose
Every docker run flag has a place in compose.yaml
compose.yaml
1services:
2  web:
3    build: ./frontend
4    ports:
5      - 5173:5173
6    environment:
7      VITE_API_URL: http://localhost:8000
8    depends_on:
9      - api
10
11  api:
12    build: ./backend
13    ports:
14      - 8000:8000
15    environment:
16      DB_URL: mongodb://db/anime
17    depends_on:
18      - db
19
20  db:
21    image: mongo:latest
22    volumes:
23      - anime:/data/db
24
25volumes:
26  anime:
L1

services

The list of containers your app needs.

L2 · 11 · 20

web · api · db

Service names. Each one becomes a container, and also a hostname the other services can use.

= --name
L3 · 21

build / image

Build from a folder that has a Dockerfile, or use a ready-made image.

= docker build / docker pull
L4

ports

"host:container", same as before.

= -p 5173:5173
L6

environment

Settings your app reads.

= -e KEY=value
L8

depends_on

Start these first, so the order is db, then api, then web.

L22

volumes (in a service)

Mount a volume or a folder.

= -v anime:/data/db
L25

volumes (top level)

Named volumes Compose creates for you.

= docker volume create
🌐 Network for free. Compose puts every service on one network, so the API reaches MongoDB at db.
▶️ One command. docker compose up builds, creates and starts everything. docker compose down removes it.

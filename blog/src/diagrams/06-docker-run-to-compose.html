Docker Compose
Every docker run flag has a place in compose.yaml
compose.yaml
services:  web:
    build: ./frontend
    ports:
      - 5173:5173
    environment:
      VITE_API_URL: http://localhost:8000
    depends_on:
      - api

  api:
    build: ./backend
    ports:
      - 8000:8000
    environment:
      DB_URL: mongodb://db/anime
    depends_on:
      - db

  db:
    image: mongo:latest
    volumes:
      - anime:/data/db

volumes:
  anime:

services

Every container your app needs.

web · api · db

Service names. Each becomes a container — and a hostname other services can use.

= --name

build / image

Build from a folder with a Dockerfile, or use a ready-made image.

= docker build / docker pull

ports

"host:container".

= -p 5173:5173

environment

Settings your app reads.

= -e KEY=value

depends_on

Start these services first: db → api → web.

volumes (in a service)

Mount a volume or a folder.

= -v anime:/data/db

volumes (top level)

Named volumes Compose creates for you.

= docker volume create
🌐 Free network: Compose puts all services on one network, so the API reaches MongoDB at db.
▶️ One command: docker compose up builds, creates and starts everything. down removes it.

Dockerfile cheat sheet
The 9 instructions you will use most
Runs at: BUILDSTARTINFO
FROMbuild

Base image to start from. Always the first line.

FROM node:22-alpine
WORKDIRbuild

Folder inside the container. Like cd (creates it too).

WORKDIR /app
COPYbuild

Copy files from your computer into the image.

COPY package*.json ./
RUNbuild

Run a command while building (install things).

RUN npm install
ARGbuild

Variable for build time only. Change with --build-arg.

ARG NODE_VERSION=22.21.1
ENVstart

Environment variable available while the app runs.

ENV PORT=8000
EXPOSEinfo

Documents the app's port. Does not publish it — -p does.

EXPOSE 5173
VOLUMEstart

Marks a folder whose data should live in a volume.

VOLUME /data/db
CMDstart

Default command when the container starts. Only one.

CMD ["npm", "run", "dev"]

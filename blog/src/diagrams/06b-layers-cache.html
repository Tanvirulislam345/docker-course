Layers & cache
Every instruction = one layer. Order matters!

❌ Copy everything first

You changed one line in App.tsx →
FROM node:22-alpine cached ⚡
WORKDIR /app cached ⚡
COPY . . changed
RUN npm install re-runs 🐢 ~60s
CMD ["npm","run","dev"] rebuilt

✅ Copy package.json first

You changed one line in App.tsx →
FROM node:22-alpine cached ⚡
WORKDIR /app cached ⚡
COPY package*.json ./ cached ⚡
RUN npm install cached ⚡ 0s
COPY . . changed
CMD ["npm","run","dev"] rebuilt
💡 Docker reuses a layer if nothing above it changed. Put things that change rarely (dependencies) near the top of the Dockerfile and things that change often (your source code) near the bottom.

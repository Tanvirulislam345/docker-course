docker compose watch
Save a file — Compose updates the container
✏️You save a file
→
👀Compose checks your
develop.watch rules
→
⚡Runs the matching action
syncfor source code

Copies the changed file into the running container. Vite or nodemon reloads it.

edit App.jsx → copied → page updates
- path: ./frontend target: /app action: sync
rebuildfor package.json, lock file, Dockerfile

Builds a new image and replaces the container, so new packages get installed.

npm install axios → build → new container
- path: ./frontend/package.json action: rebuild
sync+restartfor config read at startup

Copies the file, then restarts the container so the app reads it again.

edit config.json → copied → restart
- path: ./backend/config.json target: /app/config.json action: sync+restart

Without watch

Edit code → docker compose up --build → wait. Every time. Bind mounts help, but share everything (even node_modules) and never install new packages.

With watch

You choose which files to watch and what to do. Code syncs in a second, and a rebuild happens only when it's really needed.

react-docker · step by step
Add one flag at a time and watch what changes
1
docker build -t react-docker .
✅ Image built and named
2
docker run react-docker
❌ Vite starts, but the browser can't reach it
3
docker run -p 5173:5173 react-docker
✅ Opens at localhost:5173
4
docker run -d --name react-app -p 5173:5173 react-docker
✅ Runs in background, has a name
5
docker run -p 5173:5173 -v "$(pwd):/app" react-docker
❌ Crash: local node_modules hides the container's
6
docker run -p 5173:5173 -v "$(pwd):/app" -v /app/node_modules react-docker
✅ Edits show up live
7
docker run --rm -d --name react-app -p 5173:5173 \
  -v "$(pwd):/app" -v /app/node_modules react-docker
✅ Auto-deleted when stopped
…but look how long it got 😅

Why Docker Compose?
The same container — written once, in a file
😵 docker run (type it every time)
terminal
$ docker build -t react-docker .
$ docker run -d \
    --name react-app \
    -p 5173:5173 \
    -v "$(pwd):/app" \
    -v /app/node_modules \
    react-docker
➜
😌 compose.yaml (write it once)
compose.yaml
services:
  web:
    build:
      context: .
    ports:
      - 5173:5173
    volumes:
      - .:/app
      - /app/node_modules
$ docker compose up
📝 Saved in GitNo more copy-pasting long commands.
🧩 Many containersFrontend, backend & DB in one file.
🌐 Auto networkServices reach each other by name.
⏱️ Start orderdepends_on starts db → api → web.

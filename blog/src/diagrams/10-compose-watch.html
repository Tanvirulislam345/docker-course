docker compose watch
Save a file → Docker updates the container for you
😩 Without watch: change code → docker compose down → up --build → wait… every single time. Bind mounts help, but they share everything (even node_modules) and can be slow on Mac/Windows.
😌 With watch: you list which files to watch and what to do. Compose copies only what changed — or rebuilds only when it must.
sync

Copy changed files into the running container

✏️ edit App.jsx→📋 copied→⚡ HMR / nodemon
- path: ./frontend target: /app action: sync
Use for: source code with hot reload
rebuild

Build a new image & replace the container

📦 edit package.json→🔨 build→🔁 new container
- path: ./frontend/package.json action: rebuild
Use for: new npm packages, Dockerfile changes
sync+restart

Copy the file, then restart the container

⚙️ edit config→📋 copied→🔄 restart
- path: ./nginx.conf target: /etc/nginx/nginx.conf action: sync+restart
Use for: config files read only at startup

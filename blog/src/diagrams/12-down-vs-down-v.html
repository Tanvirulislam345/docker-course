Volumes keep your data
docker compose down vs down -v
$ docker compose down
🟢 containers removed
🌐 network removed
📦 images kept
💾 volume "anime" kept ✅
Run up again → your anime list is still there. Safe for everyday use.
$ docker compose down -v
🟢 containers removed
🌐 network removed
📦 images kept
💾 volume "anime" deleted ❌
Run up again → empty database []. Use it only for a fresh start.

Troubleshooting
Common errors & quick fixes
port is already allocated
Something else already uses 5173 / 8000 on your computer.
✅ Map another host port: -p 3000:5173 → open localhost:3000
Page doesn't load (but logs say "ready")
Vite listens only inside the container's localhost.
✅ Use "dev": "vite --host" in package.json
EACCES: permission denied
The non-root app user can't write to /app.
✅ Keep RUN chown -R app:app . before npm install
Cannot find native binding / vite: not found
The $(pwd):/app mount hid the container's node_modules.
✅ Add -v /app/node_modules
New npm package is missing in container
The node_modules volume still has the old packages.
✅ docker compose down -v then up --build
database connection failed. exiting now...
The API can't reach MongoDB, or DB_URL is wrong.
✅ Check docker compose ps, use mongodb://db/anime
Edits don't show up in the container
docker compose up alone doesn't sync files (mern-docker).
✅ Run docker compose watch (+ Vite usePolling)
Cannot connect to the Docker daemon
Docker Desktop / the docker service isn't running.
✅ Start Docker Desktop, or sudo systemctl start docker
